## 📑 프로젝트 개요 (Overview)
**Daily Bloom**은 체계적인 계획과 기록을 선호하는 사용자(특히 MBTI 'J' 유형)를 위해 설계된 모바일 최적화 데일리 플래너입니다. 복잡한 기능은 덜어내고, **캘린더**, **목표 관리**, 그리고 **친구와의 소통(Bloom)**에 집중했습니다.

- **배포 주소:** [https://dailybloomyourday.web.app](https://dailybloomyourday.web.app)
- **개발 기간:** 2025.12 ~ 2026.01

<br />

## ✨ 주요 기능 (Key Features)

### 🗓️ 스마트한 일정 관리
- **연속 일정 (#d):** `#d3 여행`과 같이 입력하면 여러 날짜에 걸친 일정을 자동으로 생성하고 달력에 매끄러운 바(Bar) 형태로 연결해 보여줍니다.
- **주간 반복 (#w):** `#w4 운동`과 같이 입력하면 매주 같은 요일에 반복되는 일정을 한 번에 등록합니다.
- **체크리스트:** 일정을 완료하면 `✔` 표시와 함께 취소선이 적용되어 달력에서 성취감을 느낄 수 있습니다.

### 🔍 고급 검색 & 이동
- **유사도 기반 검색 (Fuzzy Search):** 정확한 단어가 기억나지 않아도 비슷한 단어로 과거의 일정을 빠르게 찾아냅니다.
- **스마트 네이비게이션:** 검색 결과나 알림을 클릭하면 해당 일정이 있는 년/월의 달력 위치로 즉시 이동합니다.
- **퀵 피커:** 달력 제목을 클릭하여 원하는 년도와 월로 빠르게 점프할 수 있는 세련된 UI를 제공합니다.

### 🌸 소셜 인터랙션 (Bloom)
- **친구 태그 (@):** 일정에 `@이름`을 태그하여 친구와 일정을 공유하고 알림을 보낼 수 있습니다.
- **블룸(Bloom) 응원:** 친구의 달력을 방문하여 실시간으로 응원 메시지를 남길 수 있습니다.
- **방문자 모드:** 친구의 달력은 핑크빛 감성을 유지하되, 읽기 전용 모드로 안전하게 보호됩니다.

### 📱 모바일 최적화 (Responsive Design)
- **반응형 UI:** PC, 태블릿, 스마트폰 등 어떤 기기에서도 최적화된 화면을 보여줍니다.
- **바텀 시트 (Bottom Sheet):** 모바일에서 날짜 클릭 시 하단에서 부드럽게 올라오는 팝업을 통해 편리하게 일정을 관리합니다.

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend:** Vanilla JavaScript, Web Components, Modern CSS (Flexbox/Grid)
- **Backend:** Firebase Authentication (Google Login), Cloud Firestore (Real-time DB)
- **Deployment:** Firebase Hosting
- **Tools:** Google Analytics, Microsoft Clarity (사용자 경험 분석)

## 🚀 시작하기 (Getting Started)

1. **로그인:** 구글 계정으로 간편하게 시작하세요.
2. **일정 추가:** 달력에서 날짜를 선택하고 하단 입력창에 일정을 적어보세요. (태그 활용 권장!)
3. **친구 맺기:** 마이 블룸 페이지에서 친구의 이메일로 검색하여 서로 '블룸'을 맺어보세요.
